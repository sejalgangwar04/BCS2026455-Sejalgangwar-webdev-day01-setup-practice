## How a Browser Loads a Webpage

When a user enters a website address in a browser, the browser uses DNS (Domain Name System) to find the server's IP address. It then sends a request to the server to access the webpage. The server responds by sending the necessary website files, such as HTML, CSS, JavaScript, and images. The browser reads the HTML to understand the page structure, uses CSS to style the page, and runs JavaScript to add functionality. Finally, the browser combines everything and displays the webpage on the screen for the user.
